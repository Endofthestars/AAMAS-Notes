# Guiding Sociotechnical Systems toward Value-Norm Equilibrium

## 一句话总结

本文提出 value–norm equilibrium：STS 中 actors 的内在价值偏好与组织外在规范相互对齐，并讨论如何测量失配、以 norm revision 与 value reflection 动态引导系统。

## 方法与证据

- 将 principal–agent duo 作为 actor；values 是内在动机，norms 是可遵守或可辩护地偏离的相互期待（§1–§2）。
- 将 actor/society、行动/价值/规范/行为层面的失配作为反馈，连接 norm revision 与个体 value reflection（§2–§4）。
- 文章列出计算建模、检测量化、干预选择、动态成员与偏好变化等开放问题，未提供可运行的 equilibrium detector 或干预算法（§3–§5）。

## 适用边界与复现

- “对齐”取决于价值表示、聚合与治理权，不能由 compliance rate 单独推断；近均衡也允许某些合理不服从。
- 实施需明示 value elicitation、norm semantics、misalignment metrics、revision authority、申诉/审计与对受影响者的风险评估。
